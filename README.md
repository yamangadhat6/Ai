# Yaman AI — النسخة الأولى

مساعد AI محلي داخل المتصفح، بدون OpenAI API أو API key.

## التشغيل

هذا المشروع يعتمد على Transformers.js ويحمّل نموذج Qwen2.5-0.5B-Instruct بصيغة quantized عند أول تشغيل.

### مهم للآيباد
فتح `index.html` مباشرة من تطبيق الملفات قد يمنع بعض خصائص JavaScript modules بسبب قيود `file://`.
الأفضل استضافته كصفحة HTTPS ثابتة، ويمكن فعل ذلك من الآيباد عبر أي استضافة ملفات ثابتة أو GitHub Pages.

## المميزات الحالية
- واجهة عربية RTL
- محادثة
- حفظ المحادثة في localStorage
- نموذج AI محلي عبر WebGPU
- لا يحتاج API key
- PWA manifest
- تصميم متجاوب للآيباد والموبايل

## ملاحظة
النموذج ليس مدربًا من الصفر داخل المشروع؛ المشروع يشغّل نموذجًا مفتوح المصدر داخل المتصفح. أول تحميل يحتاج اتصالًا بالإنترنت لتنزيل ملفات النموذج، وبعد التخزين المؤقت يمكن إعادة استخدامها حسب المتصفح.
