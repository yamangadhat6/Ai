# 🧠 Local In-Browser AI Assistant

تطبيق ذكاء اصطناعي محلي يعمل بالكامل داخل المتصفح وبدون خادم أو API Key خارجي، مبني ليعمل على أجهزة الآيباد والكمبيوتر والهواتف مباشرة عبر تقنيات WebAssembly و Transformers.js.

## 🚀 المميزات:
- **Zero API Keys:** لا يحتاج اشتراك أو مفاتيح سرية.
- **Privacy Friendly:** كل العمليات الحسابية تتم على معالج جهازك محلياً.
- **PWA Ready:** يمكن تثبيته كتطبيق مستقل على شاشة الآيباد الرئيسية.
- **Modular Code:** هيكل برمجي نظيف وقابل للتطوير.

## 🛠️ التقنيات المستخدمة:
- HTML5 / CSS3 (Dark Mode)
- Vanilla JavaScript (ES Modules)
- Transformers.js (ONNX Runtime Web)
- Hosted on GitHub Pages
